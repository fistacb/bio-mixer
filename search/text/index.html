    2. BERT：隠した単語を当てる

    BERT は、文章の一部を隠して前後から当てる練習（マスク言語モデル）を大量に繰り返して、言葉の使われ方を覚えました。単語を押すと、その単語を [MASK] に隠して、BERT が考えた候補を確率付きで上位5件表示します。BERT は英語版なので、例文も英語です。

      3. ELECTRA：すり替えを見抜く

      ELECTRA は「隠して当てる」の代わりに、「すり替えられた単語を見抜く」練習をしたモデルです。小さな生成役が単語をもっともらしい別の単語にすり替え、本体の判定役がすべての単語について「本物か、すり替えか」を見分けます。単語を押すとすり替えが起きます。生成役の一番の候補で置き換える「自然なすり替え」と、少し外れた候補で置き換える「不自然なすり替え」を切り替えられます。赤いほど、判定役が「すり替えだ」と考えています （色は文の中で比べた濃さで、いちばん怪しい単語に下線が付きます。数字は判定役が出した確率です）。この判定役は小さな版なので確率は全体に低めですが、どの単語が一番怪しいかの順番に注目してください。

      BERT と ELECTRA のちがい

      BERT（Google、2018年）

      文の約15%の単語を隠して当てる練習をします。前後の両方向の文脈を使うので、言葉の意味をとらえるのが得意です。ただし、1つの文から学べるのは隠した単語の分だけです。

      ELECTRA（Google・スタンフォード大、2020年）

      すべての単語について「本物かすり替えか」を判定するので、1つの文のすべての単語から学べます。そのため、同じ計算量なら BERT より効率よく学習できます。学習が終わると、生成役は捨てて判定役だけを使います。

      BERT をそのまま検索に使うと？

      BERT は言葉の理解の土台ですが、出力をそのまま平均してベクトルにすると、検索にはあまり向きません。どんな文どうしでも似た値が出やすいからです。そこで、「意味が近い文ほどベクトルも近くなる」ように追加で学習したモデル（Sentence-BERT など）が検索に使われます。上の「文章をさがす」も、その系統のモデルです。実際に計算した値を比べると、次のようになりました。

      生物ミキサーとのつながり

      • 生物ミキサー（作る）：言葉をベクトルにして、そのベクトルの位置から絵を作ります。ここで使っている言葉のベクトル化（CLIP の文章側）も、BERT と同じ Transformer という仕組みです。
      • さがす（探す）：画像と言葉を同じ空間のベクトルにして、近いものを並べます。
      • ことばのベクトル（理解する）：BERT や ELECTRA の練習方法で言葉の使われ方を覚え、それを文の意味のベクトルに仕上げると、文章の検索ができるようになります。

      使用モデル（いずれも Apache-2.0）：BERT base uncased（Google）、ELECTRA small generator / discriminator（Google）、paraphrase-multilingual-MiniLM-L12-v2（sentence-transformers）。結果は事前に計算したもので、このページではモデルを動かしていません。例文はこのページ用に作ったものです。
